# 能量机关视觉云台

## 构建和运行

依赖 CMake、C++20 和 OpenCV；FRC 几何类型由仓库内的 `turret_kinematics` 提供。

```sh
cmake -S . -B /tmp/energy-gimbal-build
cmake --build /tmp/energy-gimbal-build --target vision_gimbal test_energy_gimbal
ctest --test-dir /tmp/energy-gimbal-build -R '^energy_gimbal$' --output-on-failure
/tmp/energy-gimbal-build/vision_gimbal
```

主程序入口为 `vision_gimbal.cpp`，保留原例程的相机和串口基础设施。默认相机 `/dev/video0`、串口 `/dev/ttyUSB_vision`；`F` 切换开火，`C` 切换颜色，`Q` 或 Esc 退出。开火默认关闭。反馈不新鲜、晚于帧到达时间或缺失时不生成有效观测；原发送线程仍会发送零增量、推杆保持、摩擦轮零速命令，需确认下位机对该命令的实际行为，并另设通信超时保护。

## 数据流和标定

1. 在 `vision_gimbal.cpp` 的全局算法参数区填写实测平面位置、圆心、半径、叶片切点直径、相机内参和畸变，以及零位下相机安装外参；示例数值未经标定。相机标定步骤见 `camera_calibration/README.md`。OpenCV 4.6 的矩阵构造器不是 constexpr，内参和畸变先以 constexpr 数组保存，再在启动时构造 OpenCV 类型。
2. 相机取帧后立即记录到达时间并快照最近一次云台反馈。反馈单位为度；基座使用 X 前、Y 左、Z 上，相机使用 OpenCV 光学坐标 X 右、Y 下、Z 前。`baseToCam` 表示相机在基座中的位姿，即其旋转将相机坐标转到基座坐标。
3. 环检测器输出框；程序按上、右、下、左顺序取框内切圆的四点。桥接层去畸变后用 IPPE 求解，并选择基座系法向最接近平面法向轴的解。四点均值构成叶片位置。启动时至少采集 20 帧、跨度 1 秒且旋转 45 度后拟合圆心、半径、速度和方向；已知法向作为平面方向参考，不强制使用预设圆心和半径。拟合相位 RMS 须小于 1.5 度、径向 RMS 不超过 2 厘米、平面 RMS 不超过 5 厘米。采样窗口最长 10 秒，拟合未通过时保持 IDLE。
4. 控制使用开环相位，PLL 只调整时间偏移；连续四帧超过 25 度进入切换，切换期间平滑发送伺服指令但禁止击发；漏检超过一秒回到 IDLE。锁定后持续积累视觉点进行多帧圆拟合，质量检查通过后每秒最多将圆心和半径各调整 5 毫米；切换检测时清空样本。
5. 按 `F` 开启开火后，目标锁定且伺服指令可用时按间隔生成推杆脉冲，默认触发电平为 0、保持电平为 1，脉冲时长 0.2 秒、最短间隔 0.8 秒；参数和摩擦轮速度均在全局算法参数区。再次按 `F` 关闭。没有命中反馈，无法确认击中或自动停止重复击发。

画面中灰色曲线为预设参考圆，青色曲线为拟合后的基座系轨迹投影；红圈为包含时间提前量的预测目标，绿色十字为画面中心，黄色线连接画面中心与预测目标。需要有效的帧时刻云台姿态；目标点仅在锁定或切换期间显示。

**限制：**框内切圆不是投影轮廓的真实四个物理切点，透视、遮挡或检测框误差会使 PnP 有偏甚至无法判定镜像解。必须用真实数据验证，必要时改为视觉提取具有固定物理对应关系的特征点；不能仅凭合成测试认定可用于实车。

## 空载调试

默认 `kEnableServo=true`、开火关闭。核对反馈、坐标、舵机方向和机械限位，检查目标位置、拟合速度及状态。上位机对 yaw/pitch 使用软限位；速度和加速度限幅由下位机伺服实现，本仓库不包含该固件，需核对其配置和推杆电平约定。

在已标定条件下从 `kDefaultTOffsetS` 开始，记录空载跟踪的相位偏差和处理时延，逐步调整该总偏移并复测不同速度、方向、切换和漏检情况。PLL 用当前观测相位校正同一个总偏移，无法单独辨识曝光延迟和弹丸飞行提前量，可能抵消飞行提前量；实际命中提前量需要独立验证，本示例不提供经过验证的弹道控制或击发安全保证。

变速扩展应替换 `PhaseModel::PhaseAt` 和 `OmegaAt`；相位初始化仍需提供能匹配实际运动的模型及足够观测，否则匀速拟合不能可靠初始化变速目标。
